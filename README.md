# translat-e-apk

Lebih dari sekadar aplikasi penerjemah, Translate-E memungkinkan kamu menerjemahkan kata atau kalimat secara langsung, menyimpan hasil terjemahan sebagai catatan, menambahkan gambar sebagai referensi visual, hingga mengorganisasi materi belajar dalam bentuk "deck".

Fitur Utama

Instant Translation - Terjemahkan kata atau kalimat secara langsung.
Save as Notes - Simpan hasil terjemahan langsung menjadi catatan pribadi.
Image Support - Tambahkan gambar untuk memperkaya konteks dan pemahaman catatan.
Deck Management - Kelompokkan catatan ke dalam deck berdasarkan topik atau kebutuhan belajar.
Deck Sharing -Bagikan deck kepada pengguna lain dan temukan materi belajar yang bisa digunakan bersama.
Personal Language Library - Bangun dan kelola koleksi kosakata serta materi bahasa milikmu sendiri.
Support the Development ❤️

Translate-E dikembangkan secara independen dan terus mengalami pengembangan untuk menghadirkan pengalaman belajar bahasa yang lebih baik. Thank you for being part of Translate-E's journey!
